SIGNALLAB / INFORMATION

Privacy policy.

A transparent explanation of the information used by this educational network monitoring application.

01 / PRIVACY

01. Overview

SignalLab is an educational project designed to demonstrate network connectivity monitoring between Amazon EC2 instances. The application displays network availability and latency through a browser-based dashboard.

02. Information displayed

The dashboard displays the target instance's private IP address, connectivity status, ping latency, and the time of the most recent network check.

This information is obtained from the monitoring backend and is used to show the current network state.

03. Personal information

The current dashboard does not provide user registration, account profiles, or forms requesting personal information. It does not intentionally collect names, email addresses, or passwords through its interface.

04. Cookies and local storage

The current dashboard JavaScript does not set cookies or store monitoring results in browser local storage. The application does not include advertising or analytics tracking scripts.

05. Server and infrastructure logs

The web server, SSH service, and AWS infrastructure may generate operational or security logs. These can include request details, timestamps, and connection information. Such logs are separate from the dashboard's displayed monitoring data.

06. Network monitoring

SignalLab uses ICMP ping requests to check connectivity with a designated AWS EC2 instance. These checks are performed by the server rather than the visitor's browser.

07. Data security

The educational deployment is accessed through an SSH tunnel. Access permissions and infrastructure security depend on the AWS configuration and operating environment. No system should be considered completely secure.

08. Policy updates

This policy describes the current educational prototype. It should be reviewed and updated if additional features, data collection, external hosting, or authentication services are introduced.
